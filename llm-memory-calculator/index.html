Where the numbers come from

  • Memory classes, the 2 GB per billion parameters rule and the mixture-of-experts rule: Intel Inference Microservices, Supported Intel platforms (updated 20 Nov 2026).
  • The 92% NUMA reservation: Environment variables.
  • Layers, KV heads and head dimension: each model's config.json on Hugging Face: . Parameter counts are rounded, from the model cards. For Qwen3.5-4B, 5B is the checkpoint's count, which includes its vision encoder; the card says 4B.
  • Qwen3.5-4B's fixed state per user (53 MB) is an estimate from its config: 24 Gated DeltaNet layers × 32 heads × 128 × 128 values plus the convolution state, counted at 4 bytes. At 2 bytes it would be about 26 MB. Check that your serving engine supports this model before relying on it.
  • The KV cache figure is calculated with the standard formula on this page, not quoted from Intel. It's an estimate for planning: measure with real prompt lengths before you set limits.

Quantization: the same model in fewer bytes

Quantization stores each weight in fewer bits. The model gets smaller and usually faster, at some cost in answer quality. Here is at , in three precisions.

Quantizing weights doesn't shrink the KV cache: that has its own precision, set to on the Memory calculator tab. INT4 is counted at about 0.6 bytes per parameter: 4-bit weights plus their scales, with some layers kept at INT8.

The catalog's containers support BF16 only today. To serve INT8 or INT4 on Xeon, compress the model with OpenVINO and serve it with OpenVINO Model Server.

How to make an INT4 or INT8 model

OpenVINO compresses a Hugging Face model in one command. INT4 here is mixed precision: mostly 4-bit, with some layers kept at 8-bit to protect quality.

# INT8 weights
optimum-cli export openvino --model microsoft/Phi-3.5-mini-instruct \
  --weight-format int8 ov_phi-3.5-mini-instruct

# INT4 weights, data-aware for better quality
optimum-cli export openvino --model microsoft/Phi-3.5-mini-instruct \
  --weight-format int4 --awq --scale-estimation --dataset wikitext2 \
  --group-size 64 --ratio 1.0 ov_phi-3.5-mini-instruct

Commands from OpenVINO's LLM Weight Compression guide. Compare answers on the customer's own prompts before and after.
